# Portafolio Web — Javier García

Portafolio personal desarrollado con React, Vite, Tailwind CSS y Framer Motion. Diseñado con estética minimalista para mostrar mis proyectos, habilidades y experiencia como desarrollador Front-End Junior.

## 🚀 Tecnologías

- React 19
- Vite 8
- Tailwind CSS v4
- Framer Motion
- Desplegado en Vercel

## ✨ Características

- Diseño responsive con menú hamburguesa en móvil
- Animaciones de entrada al hacer scroll
- Secciones: Inicio, Sobre mí, Skills, Proyectos y Contacto
